    看懂每日報告

    點範例報告裡任何一段文字，右邊會說明它的意思、怎麼算出來，以及範例中的數字代表什麼。下方有位階計算器和趨勢投票模擬，可以自己代數字試試。

    ｜

    有虛線底線的文字都可以點。也可以用 Tab 鍵移動、Enter 選取。

      位階計算器

      輸入區間最高價、最低價和收盤價，看收盤落在區間的哪個位置。

      趨勢投票模擬

      每項指標可以投多、不表態或空。至少三票同方向才判定偏多或偏空。

      顏色依台股慣例：紅色代表多（漲），綠色代表空（跌）。
