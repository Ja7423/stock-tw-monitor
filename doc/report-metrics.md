# 報告數值說明

這份文件逐項說明每日報告裡每個數字代表什麼、怎麼算出來。
指令用法和報告的大致看法請看 [Telegram Bot 使用教學](bot-usage.md)。計算邏輯都在 `src/analysis.ts`，顯示格式在 `src/report.ts`。

## 名詞與資料來源

- **K 棒**：一個交易日的開盤、最高、最低、收盤價，來自 FinMind 的台股日 K。
- **未還原價格**：所有計算都用**未還原**的價格。除權息當天的跳空會直接算進漲跌、均線和高低點，所以會和使用還原價的看盤軟體有落差。
- **可用歷史**：每次分析最多讀取最近 300 根 K 棒。新增股票時會回補約 420 個日曆天，大約 285 根。
- **三個參數**：下文的 `range`、`ma`、`pct` 是你用 `/set` 或 `/override` 設定的值，預設分別是 10、`5,10,20,60,120,240`、120。

下文說「最新一根」指資料庫裡日期最新的那根 K 棒，通常是今天。

每個數值除了計算方式，也附上「怎麼解讀」。解讀只說明數字反映了什麼價格狀態，不是買賣建議。文中的區間門檻（例如「R² 0.7 以上」）是常見的參考值，不是程式裡的判斷條件。

## 報告範例

以下數字僅為示意：

```
📊 台股監測 2026-10-30（預設區間 10 日）
偏多 1｜偏空 0｜盤整 1
━━━━━━━━━━
2330 台積電  1,050 (+1.4%)

  ⬆️ 偏多｜10日 +4.5% (+45)｜多4/空0

  斜率 +0.42%/日 R² 0.81｜7紅3黑0平｜高低點墊高

  均線乖離率
    MA5 +1.2% ✅
    MA10 +2.5% ✅
    MA20 +3.8% ✅
    MA60 +6.1% ✅
    MA120 +9.4% ✅
    MA240 +18.2% ✅
  多頭排列
  🔔 站上 MA5

  位階 120日 92%｜52週 距高 -1.9% 距低 +48.6%
```

以下依出現順序說明。

## 報告標頭

```
📊 台股監測 2026-10-30（預設區間 10 日）
偏多 1｜偏空 0｜盤整 1
```

| 項目 | 意義 |
|---|---|
| `2026-10-30` | 報告產生當天的台北日期 |
| `預設區間 10 日` | 全域設定的 `range`。有個股覆寫的股票會用自己的區間，看各股的趨勢判定 |
| `偏多 / 偏空 / 盤整` | 各趨勢判定的股票檔數。顯示「資料不足」的股票不算在內 |

## 收盤價與當日漲跌

```
2330 台積電  1,050 (+1.4%) [資料日 2026-10-29]
```

| 項目 | 計算方式 |
|---|---|
| `1,050` | 最新一根的收盤價 |
| `(+1.4%)` | 當日漲跌幅 = (最新收盤 − 前一根收盤) ÷ 前一根收盤 × 100% |
| `[資料日 …]` | 只有在最新一根的日期不是今天時才出現，代表這檔還沒有今天的資料 |

當日漲跌幅是拿**前一根的收盤**比，和一般看盤軟體的「漲跌幅」相同。這點和下面紅黑 K 的算法不同。

## 趨勢判定

```
⬆️ 偏多｜10日 +4.5% (+45)｜多4/空0
```

### 區間漲跌：`10日 +4.5% (+45)`

取最近 `range` 根 K 棒作為**觀察區間**。

- `10日`：區間實際用到的 K 棒數。新上市、歷史不夠的股票會少於 `range`。
- 起點 = 區間**第一根的開盤價**（開盤價是 0 時改用收盤價）
- 終點 = 區間**最後一根的收盤價**
- `(+45)` = 終點 − 起點
- `+4.5%` = (終點 − 起點) ÷ 起點 × 100%

起點用開盤價而不是收盤價，是為了把區間第一天本身的漲跌也算進來。

**怎麼解讀**：這段期間「從頭到尾」淨漲跌多少。它只看首尾兩個價格，中間怎麼走不知道。同樣是 +4.5%，可能是一路穩穩上漲，也可能是大跌後最後幾天急拉。過程是否穩定要搭配趨勢細節的 R² 和高低點結構來看。

### 多空投票：`多4/空0`

四項指標各投一票，每票是 +1（多）、−1（空）或 0（不表態）：

| 指標 | 投多 | 投空 | 不表態 |
|---|---|---|---|
| 區間漲跌 | 漲跌 % > 0 | 漲跌 % < 0 | 剛好 0 |
| 迴歸斜率（趨勢細節） | 斜率 > 0 | 斜率 < 0 | 剛好 0 |
| 紅黑 K（趨勢細節） | 紅 K 比黑 K 多 | 黑 K 比紅 K 多 | 一樣多 |
| 高低點結構（趨勢細節） | 高低點墊高 | 高低點下移 | 高低點交錯 |

`多` 和 `空` 是兩邊的票數。不表態的票兩邊都不算，所以兩個數字加起來可能小於 4。

### 判定結果

| 結果 | 條件 |
|---|---|
| ⬆️ 偏多 | 多 ≥ 3 |
| ⬇️ 偏空 | 空 ≥ 3 |
| ↔️ 盤整 | 其他情況，例如 `多2/空2`、`多2/空1` |

四項指標裡至少要有三項同方向才算有趨勢。

**怎麼解讀**：票數越集中，四個角度的看法越一致。

| 票數 | 意思 |
|---|---|
| `多4/空0`、`多0/空4` | 四項全部同方向，趨勢最一致 |
| `多3/空1`、`多3/空0` | 判定成立，但有一項指標不同調，可以看是哪一項 |
| `多2/空2` | 指標正反各半，方向分歧 |
| `多2/空0`、`多1/空1` 等 | 有指標不表態，訊號偏弱 |

同樣是「盤整」，`多2/空1` 偏多但不夠明確，`多1/空2` 則偏空，兩者意義不同，不要只看判定結果。

## 趨勢細節

```
斜率 +0.42%/日 R² 0.81｜7紅3黑0平｜高低點墊高
```

### 斜率與 R²

對觀察區間內的收盤價做線性迴歸：x 是第幾根（0、1、2…），y 是收盤價。

- **斜率（%/日）** = 迴歸直線的斜率 ÷ 區間收盤價平均 × 100%。
  意思是「照這條直線走，平均每根 K 棒漲跌幾 %」。除以平均價，是為了讓不同價位的股票可以直接比較。
- **R²**：收盤價和迴歸直線的貼合程度，範圍 0～1，計算方式是收盤價和時間的相關係數平方。
  - 接近 1：價格幾乎沿著直線走，趨勢很穩定
  - 接近 0：價格上下亂跳，斜率參考價值低
  - 區間內收盤價全部一樣時固定是 0

**怎麼解讀**：斜率說明方向和速度，R² 說明這個方向可不可信，兩者要一起看。

| 斜率 | R² | 意思 |
|---|---|---|
| 明顯為正 | 高（約 0.7 以上） | 穩定上漲，走勢接近一直線 |
| 明顯為負 | 高 | 穩定下跌 |
| 明顯為正或負 | 低（約 0.3 以下） | 有方向但過程震盪，斜率可能只是被幾天大漲大跌拉出來的 |
| 接近 0 | 任何 | 沒有明顯方向，橫盤整理 |

斜率的大小可以換算成區間總漲幅的感覺：`+0.42%/日` 乘上 10 根，大約是區間內漲了 4% 左右的速度。

### 紅黑 K：`7紅3黑0平`

數觀察區間內每根 K 棒：

| 類型 | 條件 |
|---|---|
| 紅 K | 收盤 > 開盤 |
| 黑 K | 收盤 < 開盤 |
| 平 | 收盤 = 開盤 |

這是拿**同一天的開盤**比，不是拿前一天收盤比。所以跳空開高後收低的日子，即使比前一天漲，也算黑 K。

**怎麼解讀**：反映「盤中」買賣力道。紅 K 多代表常常開盤後被買上去，黑 K 多代表常常開盤後被賣下來。

- 區間上漲但黑 K 比較多：漲幅可能主要來自跳空開高，盤中反而走弱。
- 區間下跌但紅 K 比較多：可能是跳空開低後盤中有買盤撐住。
- 平盤很多：成交清淡或價格變動小，常見於低價股或 ETF。

### 高低點結構

把觀察區間切成前後兩半，各取 ⌊根數 ÷ 2⌋ 根。根數是奇數時，正中間那一根不算。分別找出兩半的最高價和最低價來比較：

| 結果 | 條件 |
|---|---|
| 高低點墊高 | 後半最高 > 前半最高，**而且**後半最低 > 前半最低 |
| 高低點下移 | 後半最高 < 前半最高，**而且**後半最低 < 前半最低 |
| 高低點交錯 | 其他情況，例如高點創高但低點也破低（擴散），或兩者都收斂 |

這裡用的是每根 K 棒的最高價和最低價，不是收盤價。

**怎麼解讀**：這是技術分析裡「高點越來越高、低點越來越高」的趨勢定義，比首尾漲跌更能看出過程。

- **墊高**：回檔的低點守在前面的低點之上，上漲結構完整。
- **下移**：反彈的高點過不了前面的高點，下跌結構完整。
- **交錯**：可能是高點創高、低點也破低的大幅震盪，也可能是高點變低、低點變高的收斂整理。這時看前兩項指標比較準。

## 均線（MA）

```
均線乖離率
  MA5 +1.2% ✅
  MA20 -0.8% ❌
  MA240 —
多頭排列
🔔 站上 MA5、跌破 MA20
```

均線用的是全部可用歷史，不受觀察區間 `range` 影響。

### 每條均線

- **MA 值**：最近 N 根收盤價的簡單平均（SMA），N 是均線週期。
- **乖離 %** = (最新收盤 − MA 值) ÷ MA 值 × 100%
- **✅ / ❌**：乖離 ≥ 0 顯示 ✅，代表收盤在均線之上或剛好相等；< 0 顯示 ❌。
- **`MA240 —`**：歷史 K 棒少於 N 根，算不出這條均線。

**怎麼解讀**：均線可以想成最近 N 天進場的人的大致平均成本，乖離就是現價和這個平均成本差多少。（實際算的是收盤價的簡單平均，沒有考慮成交量，所以只是概略的成本。）

- **✅ 在均線之上**：最近 N 天進場的人平均是賺錢的。❌ 則平均是賠錢的。
- **週期代表時間尺度**：MA5、MA10 看短線（一兩週），MA20、MA60 看中期（月線、季線），MA120、MA240 看長期（半年線、年線）。
- **乖離大小**：乖離越大，代表價格離平均成本越遠、短期漲跌越急。短天期均線的乖離通常比較小，例如 MA5 乖離 +8% 很少見，MA240 乖離 +8% 則很常見，所以要拿同一條均線的歷史來比，不能直接跨週期比大小。
- **短天期 ✅、長天期 ❌**：短線反彈，但還在長期的平均成本之下。反過來（短 ❌、長 ✅）則是長期上漲中的短線回檔。

### 排列狀態

只拿算得出來的均線，依週期由短到長排序，逐一比較相鄰兩條：

| 結果 | 條件 |
|---|---|
| 多頭排列 | 每一條短均線都 > 下一條較長的均線，例如 MA5 > MA10 > MA20 > … |
| 空頭排列 | 每一條短均線都 < 下一條較長的均線 |
| 均線糾結 | 其他情況 |

- 算得出來的均線少於 2 條時，不顯示這一行。
- 顯示 `—` 的均線不參與比較。例如 MA240 是 `—`，排列狀態就只看 MA5 到 MA120。

**怎麼解讀**：

- **多頭排列**：越近期的平均成本越高，代表價格一路往上墊，是長時間上漲後才會出現的狀態。
- **空頭排列**：越近期的平均成本越低，長時間下跌後出現。
- **均線糾結**：最常見的狀態，代表趨勢正在轉換或沒有明確方向。可以看是哪幾條均線交叉，例如只有 MA5 跌破 MA10，通常只是短線回檔。

排列狀態變化得比價格慢很多，適合確認中長期趨勢，不適合用來判斷短線轉折。

### 🔔 站上 / 跌破

比較前一根和最新一根相對於均線的位置，兩根各自用當天的均線值：

| 訊號 | 條件 |
|---|---|
| 站上 MA N | 前一根收盤 ≤ 前一根的 MA，**而且**最新收盤 > 最新的 MA |
| 跌破 MA N | 前一根收盤 ≥ 前一根的 MA，**而且**最新收盤 < 最新的 MA |

- 要有 N + 1 根 K 棒才算得出前一根的 MA，否則不會出現訊號。
- 沒有任何均線出現訊號時，不顯示這一行。

**怎麼解讀**：價格今天剛好穿過某條均線。

- 只看一天的收盤，價格在均線附近來回時會反覆出現站上、跌破，短天期均線（MA5、MA10）特別常見。
- 長天期均線（MA60 以上）的站上、跌破比較少發生，出現時通常比較值得注意。
- 可以搭配下一個交易日的報告確認：站上後隔天乖離仍是 ✅，比只站上一天更有參考價值。

## 最後一行：價格位階

```
位階 120日 92%｜52週 距高 -1.9% 距低 +48.6%
```

### 位階：`120日 92%`

取最近 `pct` 根 K 棒，找出這段期間的最高價（H）和最低價（L）：

**位階 = (最新收盤 − L) ÷ (H − L) × 100%**

- 0% 代表收在這段期間的最低點，100% 代表收在最高點。
- `120日` 是實際用到的 K 棒數，歷史不夠時會少於 `pct`。
- H 等於 L 時（價格完全沒動）固定顯示 50%。

**例子**：最近 120 根 K 棒的最低價 800、最高價 1,100，今天收盤 1,076：

```
(1,076 − 800) ÷ (1,100 − 800) = 276 ÷ 300 = 92%
```

從 800 到 1,100 這段區間，現價已經走了 92% 的距離，離高點只差 24 元。

**怎麼解讀**：

| 位階 | 意思 |
|---|---|
| 80% 以上 | 收在近期高點附近，可能正在強勢創高，也可能處於相對高檔 |
| 20%～80% | 在區間中段 |
| 20% 以下 | 收在近期低點附近 |

- 位階高不等於「太貴」，位階低也不等於「便宜」。強勢股可以長時間維持在 90% 以上，弱勢股也可以一直在 10% 以下。搭配趨勢判定一起看：偏多加上高位階是「強勢」，盤整加上高位階則是「漲到區間上緣」。
- 天數由 `pct` 參數決定。改成 `/set pct 240` 會看近一年的位置，數字會比 120 日穩定、變化較慢。

**注意**：這是**現價在高低區間中的相對位置**，概念和 KD 指標的 RSV 相同，只是 KD 通常看 9 天，這裡預設看 120 天。它**不是**「贏過 92% 的交易日」：

- 它只看最高和最低兩個點，不看中間每天的價格分布。例如 120 天裡只有一天急拉到 1,100、其他時間都在 800～850，今天收 900 的位階只有 33%，但其實已經比九成以上的交易日都高。
- 高低點用的是每天的最高價、最低價，不是收盤價。所以就算今天收在區間內最高的收盤價，位階也可能不到 100%。

### 52 週：`距高 -1.9% 距低 +48.6%`

取最近 250 根 K 棒（約一年的交易日），找出最高價和最低價：

- **距高** = (最新收盤 − 最高價) ÷ 最高價 × 100%，一定 ≤ 0。0% 代表收在一年新高。
- **距低** = (最新收盤 − 最低價) ÷ 最低價 × 100%，一定 ≥ 0。

不滿 250 根時會顯示 `52週(僅180日)`，表示只用了 180 根計算。

**怎麼解讀**：一年內的價格範圍，以現價為準往上、往下各差多少。

- **距高接近 0%**：接近一年新高，上方沒有一年內的套牢價位。
- **距高很大**（例如 -30%）：從一年高點跌了很多，要回到高點需要漲的幅度比這個數字更大。跌 30% 後要漲約 43% 才回得去，因為基數變小了。
- **距低很大**：離一年低點很遠，代表這一年已經漲了不少。

和上面的位階一起看：位階看中期（預設 120 日）、52 週看一年。例如位階 90% 但距高 -25%，代表近半年在反彈，但還沒回到一年前的高點。

## 綜合解讀範例

以文件開頭的範例報告（台積電）為例：

- **趨勢**：`多4/空0`，四項指標全部偏多。斜率 +0.42%/日、R² 0.81，是穩定上漲而不是急拉。高低點墊高，上漲結構完整。
- **均線**：六條均線全部 ✅，而且多頭排列，短中長期都在上漲。MA240 乖離 +18.2%，現價比一年平均成本高將近兩成。
- **訊號**：今天站上 MA5，代表前一天收盤在 MA5 之下（或剛好相等），今天收回到上方，是上漲途中的短暫回檔後再站回。
- **位階**：120 日位階 92%、距 52 週高點只有 -1.9%，收在近半年和近一年的高點附近。

整體來說，這是「趨勢明確向上、價格位在高檔」的狀態。

## 其他訊息

| 訊息 | 意義 |
|---|---|
| `⚠️ 資料不足，無法分析` | 這檔的 K 棒少於 2 根 |
| 報告最後的 `⚠️ 更新失敗` | 這次向 FinMind 抓資料失敗的股票和原因。這些股票仍會用資料庫裡既有的 K 棒分析 |

## 數字顯示格式

| 項目 | 格式 |
|---|---|
