# Telegram Bot 使用教學

這份文件說明怎麼用 Telegram 指令管理監測清單、調整分析參數、記錄持股，以及怎麼看每日報告。
部署和環境設定請看 [README](../README.md)。

## 快速開始

1. 在 Telegram 打開你的 bot，傳 `/start` 會出現指令說明。
2. 用 `/add 2330 2317` 加入想監測的股票。
3. 傳 `/report` 立刻看一次報告。
4. 之後每個交易日 15:00 左右會自動收到報告，不需要做任何事。
5. 想追蹤自己的持股，用 `/buy 2330 1000 580` 記錄買進，`/holdings` 查看持股與淨值。詳見[持股追蹤](#持股追蹤)。

> bot 只回應 `ALLOWED_CHAT_ID` 這個 chat。其他人傳訊息會直接被忽略，不會有任何回覆。

| `/reset <代號>` | 清除個股覆寫 |
| `/buy`、`/sell <代號> <股數> <價格> [日期]` | 記錄買進、賣出 |

## 管理監測清單

### 新增：`/add`

```
/add 2330
/add 2330 2317 0050 00632R
```

- 一次最多 10 檔，用空白分隔。重複的代號會自動去掉。
- 代號格式是 4～6 位數字，後面可以帶一個英文字母，例如 `00632R`。英文字母大小寫都可以。
- 新增時會向 FinMind 查詢股票名稱，並回補約 420 個日曆天（約 285 根 K 棒）的日 K，所以會花幾秒鐘。

每檔會各自回覆結果：

```
✅ 2330 台積電 已新增
➖ 2317 已在清單中
❌ 9999 查無此股票
```

如果股票已加入清單，但回補日 K 失敗（例如 FinMind 額度用完），會回 `⚠️ 0050 元大台灣50 已新增，歷史資料稍後補抓（錯誤原因）`。這檔已經在清單裡，不用再 `/add`，下次產生報告時會自動補抓。

### 刪除：`/del`

```
/del 2330
/del 2330 2317
```

可以一次刪多檔。刪除時會一併清掉該股票的個股覆寫和已存的日 K 資料，之後重新 `/add` 會再回補一次。
有交易紀錄的股票例外：日 K 會保留，因為持股的估值和趨勢要用到。

### 查看清單：`/list`

```
📋 監測清單（3 檔）
• 2330 台積電
• 2317 鴻海  [區間 20 日｜MA 5/20/60]
• 0050 元大台灣50
```

有設個股覆寫的股票，會在後面用 `[ ]` 標示覆寫了哪些參數。

### 立即產生報告：`/report`

bot 會先回「⏳ 產生報告中…」，接著送出報告。
`/report` 不受「一天只推播一次」的限制，當天已經收過自動報告也可以再產生。

### 查看狀態：`/status`

顯示今天自動報告的執行結果、FinMind token 這一小時用了多少請求，以及每日排程要同步幾檔：

```
🩺 系統狀態 2026-10-31
今日排程：⚠️ FinMind 額度用完，已先發部分報告，等下一次排程補跑
執行時間：15:00
錯誤內容：
  5274: FinMind 每小時請求額度已用完，下一次排程會自動重試
FinMind 額度：600 / 600（本小時）  ⚠️ 已用完
每日同步：3 檔（監測 2、持股 2）｜每次排程約 5 / 50 個對外請求
```

| 今日排程 | 意思 |
|---|---|
| `尚未執行` | 今天的排程還沒跑，或今天是週末 |
| `✅ 已推播` | 今天的自動報告已送出，不會再推播 |
| `⏸ 沒有當天資料` | 休市或 FinMind 還沒更新，等 16:00 補跑 |
| `⚠️ FinMind 額度用完` | 已先送出不完整的報告，16:00 會補抓並重發 |
| `❌ 報告產生失敗` | 報告流程出錯，錯誤內容會列在下面 |

- 執行時間是最後一次排程執行的台北時間。手動 `/report` 不會更新這裡的狀態。
- 查詢額度本身不會消耗 FinMind 額度。FinMind 額度是算在 token 上的，同一個 token 在其他地方（例如本機的回測腳本）用掉的次數也會算進來。
- 每日同步是監測清單和目前持股的聯集，兩邊都有的股票只算一次。對外請求數是估計值：每檔 1 次 FinMind，再加上報告約每 10 檔一則、持股摘要約每 40 檔一則 Telegram 訊息。Workers 免費方案每次執行約可發 50 個對外請求，合計超過 40 檔時，`/add` 和 `/buy` 會附上警告，但不會阻擋。

## 調整分析參數

分析有三個參數：

| 參數 | 意義 | 預設 | 可設範圍 |
|---|---|---|---|
| `range` | 觀察區間：用最近幾根 K 棒判斷趨勢 | 10 | 2～120 |
| `ma` | 均線週期，用逗號分隔 | 5,10,20,60,120,240 | 每條 2～240，最多 8 條 |
| `pct` | 位階百分位區間：用最近幾根 K 棒計算現價位階 | 120 | 5～250 |

上限受限於回補的歷史長度（約 285 根 K 棒）。

### 全域設定：`/settings`、`/set`

`/settings` 查看目前的設定：

```
⚙️ 全域設定
區間 10 日｜MA 5/10/20/60/120/240｜百分位 120 日
手續費 2.8 折｜整股最低 1 元｜零股最低 1 元
排程：週一至週五 15:00（16:00 補跑）
```

手續費設定只用在持股追蹤，見[手續費與證交稅](#手續費與證交稅)。

`/set` 修改全域設定，對所有沒有覆寫的股票生效：

```
/set range 20
/set ma 5,20,60,240
/set pct 240
```

- `/set` 一次只能改一個項目，要改三項就傳三次。
- 均線週期可以用全形逗號 `，`，順序不拘，會自動排序並去掉重複。

### 個股覆寫：`/override`、`/reset`

想讓某檔股票用不同參數時，用 `/override`：

```
/override 2330 range=20
/override 2330 range=20 ma=5,10,20 pct=60
```

- 參數格式是 `key=value`，三個參數可以任意挑，不用全給。沒給的參數沿用全域設定。
- 股票要先 `/add` 進清單才能設覆寫，否則會回「不在清單中」。
- 再次 `/override` 同一檔時，只會更新這次有給的參數。

改回全域設定：

```
/reset 2330
```

## 每日自動報告

- **時間**：週一到週五，台北時間 15:00。15:00 時如果清單裡沒有任何一檔有當天的 K 棒，就當作休市或資料還沒更新，不發報告，16:00 再補跑一次。
- **次數**：同一天只會自動推播一次。
- **長度**：股票很多時，報告會拆成好幾則訊息，但不會把同一檔股票拆開。
- **持股摘要**：有持股時，報告後面會接著送一則持股摘要，見[每日持股摘要](#每日持股摘要)。監測清單是空的、只有持股時，也會照常推播。

### 報告範例

以下數字僅為示意：

```
📊 台股監測 2026-10-30（預設區間 10 日）
偏多 1｜偏空 0｜盤整 1
━━━━━━━━━━
2330 台積電  1,050 (+1.4%)

  ⬆️ 偏多｜10日 +4.5% (+45)｜多4/空0

  斜率 +0.42%/日 R² 0.81｜7紅3黑0平｜高低點墊高

  均線乖離率
    MA5 +1.2% ✅
    MA10 +2.5% ✅
    MA20 +3.8% ✅
    MA60 +6.1% ✅
    MA120 +9.4% ✅
    MA240 +18.2% ✅
  多頭排列
  🔔 站上 MA5

  位階 120日 92%｜52週 距高 -1.9% 距低 +48.6%
━━━━━━━━━━
2317 鴻海  ...
```

### 怎麼看報告

這裡是簡要說明。在 Telegram 傳 `/explain` 也能看到欄位說明。每個數值的完整計算方式請看 [報告數值說明](report-metrics.md)。

**股票與收盤價**

`2330 台積電  1,050 (+1.4%)`：代號、名稱、最新收盤價、當日漲跌幅。
如果後面出現 `[資料日 2026-10-29]`，代表這檔還沒有今天的資料，顯示的是最近一個交易日。

**趨勢判定**

`⬆️ 偏多｜10日 +4.5% (+45)｜多4/空0`

- 判定結果：⬆️ 偏多、⬇️ 偏空、↔️ 盤整。
- `10日 +4.5% (+45)`：區間第一根的開盤價到最後一根收盤價的漲跌。
- `多4/空0`：四項指標的投票結果，3 票以上同方向才判定為偏多或偏空，否則為盤整。四項指標是首尾漲跌、迴歸斜率、紅黑 K 數量、高低點結構。

**趨勢細節**

`斜率 +0.42%/日 R² 0.81｜7紅3黑0平｜高低點墊高`

- 斜率：區間收盤價線性迴歸的斜率，換算成每日 %。R² 越接近 1，代表走勢越接近一直線，趨勢越明確。
- 紅黑 K：區間內紅 K、黑 K、平盤各幾根。
- 高低點結構：把區間分成前後兩半，比較兩半的最高點和最低點。
  - 高低點墊高：後半段的高點和低點都比前半段高
  - 高低點下移：後半段的高點和低點都比前半段低
  - 高低點交錯：其他情況

**均線乖離率（每條均線一行）**

`MA5 +1.2% ✅`

- 每條均線後面是現價和該均線的乖離：✅ 代表現價在均線之上，❌ 代表在均線之下。
- 顯示 `MA240 —` 代表歷史資料還不夠計算這條均線。
- 排列狀態：
  - 多頭排列：短天期均線都在長天期均線之上
  - 空頭排列：短天期均線都在長天期均線之下
  - 均線糾結：其他情況

**🔔 均線訊號（有才顯示）**

`🔔 站上 MA5`：前一天收盤在均線之下（或剛好等於），今天收盤在均線之上，就是「站上」；反過來就是「跌破」。

**最後一行：價格位階**

`位階 120日 92%｜52週 距高 -1.9% 距低 +48.6%`

- 位階百分位：現價在近 N 日最高價到最低價之間的位置。0% 是區間最低，100% 是區間最高。
- 52 週：現價距離近 250 根 K 棒最高點和最低點的 %。資料不足 250 根時會顯示 `52週(僅180日)`。

**其他訊息**

- `⚠️ 資料不足，無法分析`：這檔的 K 棒還不夠計算。
- 報告最後的 `⚠️ 更新失敗`：列出這次向 FinMind 抓資料失敗的股票和原因。

## 持股追蹤

持股追蹤和監測清單是分開的：買進的股票不會自動加入監測清單，監測清單的 `range`、`ma`、`pct` 也不影響持股的計算。持股用收盤價估值，所以盤中查詢時看到的是最近一個交易日的收盤價。以下範例的數字僅為示意。

### 記錄買賣：`/buy`、`/sell`

```
/buy 2330 1000 580.5
/buy 2330 500 600 10/15
/sell 2330 300 650 2026-10-20
/sell 0050 50 180 fee=1 tax=9
```

- 參數順序固定：`代號 股數 價格 [日期] [fee=手續費] [tax=證交稅]`。
- 數量一律是**股**，支援零股。1 張要寫 `1000`。
- 日期可以省略，省略就是今天。可以寫 `2026-10-15` 或 `10/15`（當成今年）。不能是未來的日期，過去的日期都可以，忘了記的交易可以事後補登。
- 手續費和證交稅會自動算，並在記錄的當下存起來，之後改 `/set fee` 不會影響已經記錄的交易。對帳單上的金額不一樣時，用 `fee=`、`tax=` 覆寫。
- 第一次記錄某檔股票時，會向 FinMind 查股票名稱。查不到或 FinMind 出錯（例如額度用完）時不會記錄，請稍後再試。監測清單裡已有的股票不用查。
- 記錄後會回補交易日以後的日 K。回補失敗時交易照樣成立，回覆會附上 `⚠️ 歷史價格稍後補抓`，每日排程會再補。

```
✅ 2330 台積電 已記錄
#3 2026-10-20 賣 300 股 @ 650｜費 54 稅 585｜損益 +14,322
持有 1,200 股｜均價 586.23
```

`#3` 是交易編號，刪除時要用。

### 平均成本與已實現損益

- **均價**用移動加權平均，含買進手續費：`持有成本 ÷ 持有股數`。
- **賣出**時按股數比例扣掉持有成本，所以均價不變。該筆的已實現損益 = 賣出金額 − 手續費 − 證交稅 − 扣掉的成本。
- 全部賣光後再買進，均價從頭算。
- 補登或刪除交易後，所有數字會依交易日期重新計算，之後每一筆賣出的損益都會跟著更正。同一天有多筆時，依記錄的先後順序。
- 會讓任何一天的股數變成負數的交易（賣超，或刪掉一筆之後的賣出靠它的買進）不會被接受，回覆會指出是哪一天。

### 股利：`/div`

```
/div 2330 cash 4500 10/16
/div 2330 stock 50 8/1
```

- 現金股利填**實際入帳的總金額**（已扣二代健保補充保費和匯費），日期用入帳日，算進已實現報酬。
- 股票股利填配到的**股數**，日期用除權日。以 0 成本加入持股，所以均價會下降。
- 股票要先有交易紀錄才能記股利。
- 股價是未還原價格，除息日股價下跌會讓未實現報酬看起來變差，記錄現金股利後，「累計已實現」和總損益會補回這部分。

### 刪除交易：`/tradedel`

```
/tradedel 12
```

不會再跟你確認，直接刪除，並回覆被刪的那筆內容，萬一刪錯可以照著重新記錄。編號可以在 `/pos` 的交易紀錄裡找到。沒有編輯功能，記錯了就刪掉重記。

### 持股清單：`/holdings`

```
💼 持股（2 檔）
━━━━━━━━━━
2330 台積電  1,200 股
  均價 586.23｜現價 1,050｜淨值 1,256,327
  未實現 +552,851 (+78.6%)
━━━━━━━━━━
0050 元大台灣50  100 股 [資料日 2026-10-29]
  均價 150.05｜現價 160｜淨值 15,977
  未實現 +972 (+6.5%)
━━━━━━━━━━
總成本 718,481｜總市值 1,276,000｜總淨值 1,272,304
未實現 +553,823 (+77.1%)
累計已實現 +18,822（價差 +14,322｜股利 +4,500）
```

- 依淨值從大到小排序。全部賣光的股票不會列出，但它的已實現損益會算進「累計已實現」。
- **淨值** = 市值 − 預估的賣出手續費 − 預估的證交稅，也就是「現在全部賣掉能拿回多少」。
- **未實現** = 淨值 − 持有成本，報酬率 = 未實現 ÷ 持有成本。
- `[資料日 …]` 表示那檔還沒有今天的收盤價，用的是最近一個交易日。
- 剛記錄、還沒有任何價格的股票會顯示 `⚠️ 尚無價格資料`，不算進總市值和淨值。

### 個股明細：`/pos`

```
📄 2330 台積電
持有 1,200 股｜均價 586.23｜成本 703,476
現價 1,050｜淨值 1,256,327｜未實現 +552,851 (+78.6%)
已實現 +18,822（價差 +14,322｜股利 +4,500）

交易紀錄
#1 2026-03-02 買 1,000 股 @ 560｜費 223
#2 2026-05-10 買 500 股 @ 620｜費 123
#4 2026-07-16 現金股利 4,500
#3 2026-10-20 賣 300 股 @ 650｜費 54 稅 585｜損益 +14,322
```

已經賣光的股票也能查，第二行會顯示 `已出清`。交易很多時會拆成多則訊息。

### 趨勢：`/trend`

```
/trend            整個投資組合，最近 60 個交易日
/trend 2330       單一股票
/trend 2330 120   最近 120 個交易日（5～250）
```

```
📈 持股趨勢 2026-08-05 ~ 2026-10-30（60 交易日）
未實現報酬率 ▃▄▄▅▆▅▆▇██▇▆
日期｜報酬率｜未實現損益｜總損益｜淨值
08/05｜+62.1%｜+380,123｜+380,123｜1,000,456
...
10/30｜+77.1%｜+553,823｜+572,645｜1,272,304
```

- 每 5 個交易日列一行，最後一行一定是最新的交易日。sparkline 畫的是這些點的未實現報酬率。
- **總損益** = 未實現 + 累計已實現（含股利）。賣出賺錢的部位時，未實現報酬率會下降，但總損益不受買賣影響，比較適合看長期績效。
- 每次查詢都從交易紀錄重新計算，補登或刪除交易後，過去的趨勢也會更正。過去日期的淨值用的是目前的手續費設定。

### 每日持股摘要

每日報告送出後，會接著送一則持股摘要，內容和 `/holdings` 相同，多一行損益：

```
今日損益 +12,345
```

今日損益 = 今天的總損益 − 上一個交易日的總損益，當天買進投入的資金不會被算成獲利。持股還沒有今天的收盤價時，會改成 `2026-10-29 損益 …`，標出是哪一天。手動 `/report` 也會附上持股摘要。

### 手續費與證交稅

| 項目 | 計算方式 |
|---|---|
| 手續費 | max(⌊成交金額 × 0.1425% × 折扣⌋, 最低手續費)。股數未滿 1000 股時用零股的最低手續費 |
| 證交稅（賣出） | ⌊成交金額 × 稅率⌋。一般股票 0.3%；代號 `00` 開頭的 ETF 0.1%；`00` 開頭、`B` 結尾的債券 ETF 0% |

金額都無條件捨去。預設是國泰證券電子下單的 2.8 折、最低 1 元，請拿一張對帳單核對，不一樣的話用 `/set` 修改：

```
/set fee 0.28       折扣（0.28 = 2.8 折，1 = 無折扣）
/set feemin 20      整股每筆最低手續費
/set feeminodd 1    零股每筆最低手續費
```

債券 ETF 停徵證交稅是有期限的政策；期滿後或遇到其他特例（例如 ETN），用 `tax=` 覆寫。

### 不支援的情況

- 融資、融券、當沖。
- 減資、股票分割、合併換股：可以用一筆賣出加一筆買進手動調整。例如 1 拆 4：用 `/pos` 顯示的均價賣出全部股數，再以「均價 ÷ 4」買進 4 倍股數，兩筆都加上 `fee=0 tax=0`。均價有四捨五入，已實現裡可能多出幾元的差額。

## 常見問題

**傳指令沒有任何回應？**
確認你是從 `ALLOWED_CHAT_ID` 那個 chat 傳的。如果還是沒回應，可能是 webhook 沒設好，請依 README 重新執行 `scripts/set-webhook.sh`。

**今天沒收到自動報告？**
可能是休市，或 16:00 時 FinMind 仍然沒有當天的資料。先傳 `/status` 看今天排程的狀態和錯誤內容，再傳 `/report` 手動產生，看看最新資料日是哪一天。

**均線和實際看盤軟體不一樣？**
股價使用的是**未還原**價格，除權息造成的跳空會影響長天期均線，和使用還原價的軟體會有落差。

**清單可以放幾檔？**
監測清單加上持股，合計建議 40 檔以內。Workers 免費方案單次執行約可發 50 個對外請求，每日報告每檔約用 1 個。`/status` 會顯示目前的估計值。

**持股的金額和券商 App 不一樣？**
先確認 `/settings` 的手續費折扣和最低手續費和你的券商一致。已經記錄的交易，手續費和稅是記錄當下算好的，改設定不會改到它們；不一致的那幾筆，可以刪掉後用 `fee=`、`tax=` 重記。

## 錯誤訊息對照

| 訊息 | 原因 |
|---|---|
| `股票代號格式錯誤：XXX` | 代號不是 4～6 位數字加上可選的一個英文字母 |
| `一次最多新增 10 檔` | `/add` 超過 10 檔，請分批新增 |
| `用法：/set range 20、/set ma 5,20,60、/set pct 120、/set fee 0.28` | `/set` 少了項目或值 |
| `觀察區間 必須是 2~120 的整數` | 數值超出範圍，`均線週期`、`百分位區間` 的訊息也是同樣格式 |
| `最多 8 條均線` | `ma` 給了超過 8 個週期 |
| `參數格式錯誤：「range20」，應為 key=value` | `/override` 參數少了 `=` |
| `未知參數「xxx」，可用：range、ma、pct` | 參數名稱打錯 |
| `看不懂的指令：/xxx` | 指令不存在，傳 `/help` 查看用法 |
| `格式：代號 股數 價格 [日期] …` | `/buy`、`/sell` 少了參數 |
| `不能記錄未來的日期` | 交易日期在今天之後 |
| `2330 在 2026-10-20 的股數會變成負數，未記錄` | 賣出的股數超過那天的持股，或補登的日期太早 |
| `刪除後 2330 在 … 的股數會變成負數，未刪除` | 要刪的買進是之後某筆賣出的來源，先刪那筆賣出 |
| `沒有 2330 的交易紀錄，請先 /buy` | 股利只能記在有交易紀錄的股票上 |
| `FinMind 每小時請求額度已用完` | token 這一小時的 600 次請求用完了，等下一個小時再試，或傳 `/status` 查看用量 |
